# نور — نسخة آيفون (SwiftUI)

نفس محرك التصحيح اللي بنيناه لأندرويد، منقول للـ Swift بالكامل.
**محتاج ماك + Xcode** عشان تتبني وتتسطّب على الآيفون (آبل مش بتسمح ببناء iOS على ويندوز/لينكس).

---

## الملفات

```
Noor-iOS/
├─ NoorKit/                       حزمة Swift فيها المنطق (مفيش واجهة)
│  ├─ Package.swift
│  └─ Sources/NoorKit/
│     ├─ ReciteCheck.swift        محرك التصحيح (تطبيع · هيكل حروف · تشابه · DP)

├─ Noor/                          تطبيق SwiftUI
│  ├─ NoorApp.swift               نقطة البداية
│  ├─ DesignSystem.swift          الألوان والكروت والأزرار وشريط المستوى
│  ├─ ReciteView.swift            الوضع الحر: التسجيل + «فحص» + التقرير

└─ project.yml                    تعريف مشروع Xcode (لـ xcodegen)
```

## البناء (طريقتين)

### أ) بـ xcodegen (أسرع)

```bash
brew install xcodegen
cd Noor-iOS
xcodegen generate
open Noor.xcodeproj
```

في Xcode:
1. اختار الـtarget **Noor** ← تبويب **Signing & Capabilities**.
2. **Team** = حسابك (Personal Team يكفي).
3. Bundle Identifier: غيّره لو عايز (`com.noor.islamic` بيحتاج يكون فريد).
4. وصّل الآيفون ← اختار الجهاز ← **Run** (⌘R).

### ب) من غير xcodegen

1. Xcode ← **File ▸ New ▸ Project ▸ App** (SwiftUI, اسمه Noor).
2. **File ▸ Add Package Dependencies… ▸ Add Local…** واختار مجلد `NoorKit`.
3. اسحب ملفات `Noor/*.swift` للمشروع (عدا `Info.plist`).
4. استبدل `Info.plist` باللي هنا (أو ضيف المفاتيح يدوي):
   - `NSMicrophoneUsageDescription`
   - `NSSpeechRecognitionUsageDescription`
   - `UIBackgroundModes = audio`
5. **Run**.

> أول مرة على الآيفون: **Settings ← General ← VPN & Device Management ← Trust** للحساب بتاعك.
> لو التعرّف الصوتي مش بيرجّع نص: **Settings ← Siri & Search ← Dictation** لازم تكون مفعّلة، و**Keyboard ← Enable Dictation**.

## اللي اتنقل بالحرف من أندرويد

| الحاجة | التفاصيل |
|---|---|
| التطبيع العثماني | بيتشال التشكيل وعلامات الوقف والتطويل، و`ٱ أ إ آ` → `ا`، `ة` → `ه`، `ى ئ` → `ي`، و`ء` لوحدها بتتشال |
| هيكل الحروف | مقارنة بدون ا/و/ي — «العلمين» تُقبل كـ«العالمين» |
| التشابه | Levenshtein: قبول عند ≥ ٠٫٦ |
| المحاذاة | DP كلمة‑بكلمة (2.0 / 1.4 / 0.9 / 0.2 / −1.2 وفجوة −1.2) — كلمة ناقصة مش بتزحزح باقي الصفحة |
| الحركات | بتتقاس على الكلمات اللي حروفها صح بس، والمواضع اللي التعرّف مابلّغش عنها **مش أخطاء** |
| التقرير | نظرة عامة + كارت لكل آية بكلمات ملوّنة + قايمة واحدة بكل الأخطاء |
| بدون تشكيل | التقرير بيظهر بالنص المجرّد زي ما طلبت |

## اللي مختلف عن أندرويد (بسبب iOS)

- التعرّف بيستخدم **SFSpeechRecognizer** — أحيانًا بيشتغل **على الجهاز** بدون إنترنت (لو الجهاز بيدعم `supportsOnDeviceRecognition`).
- iOS بيقطع مهمة التعرّف كل ~٦٠ ثانية → التطبيق **بيعيدها بصمت** في نفس الجلسة، فالتسجيل مستمر.
- الصوت بيتحمّل من `everyayah.com` بسلسلة بدائل (القارئ المختار ثم الباقي).

---

## قبل ما تبعتها للـ App Store

- الآيفون لازم يكون iOS 16 أو أحدث.
- التطبيق بيطلب أذونات المايك والتعرّف وقت الاستخدام، ومكتوب في `Info.plist` سبب كل إذن (مطلوب للـ Review).
- لو هتحتاج بيانات مواقيت الصلاة والقبلة والأذكار (زي نسخة أندرويد) قوللي وأضيفهم في نفس النسخة.
